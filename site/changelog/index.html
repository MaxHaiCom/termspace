更新日志

改了什么

修掉的安全问题会单列出来 —— 藏起来对谁都没好处。 当前版本号从更新源实时读取，这一页不写死任何版本。

0.4.1
2026-08-13
当前

修复

  • 终端不再继承一份陈旧的环境快照 —— tmux 的服务进程活得比 app 久， 而它的全局环境是第一次启动那一刻的整份快照，此后再也不变。 本机实测那份快照来自 20 天前的一次开发运行，于是新建的每个终端都继承着 一个早已结束的会话的身份（CLI 会以为自己是那个会话的子进程、 以为自己跑在另一个终端模拟器里、拿到别的节点的编号）。 现在每次启动会就地清掉这类「某一次进程身份」的变量， 不动你自己 shell 里 export 的东西，也不影响已经开着的终端
  • 额度查询失败不再谎报成「仅管理员可查询」 —— 一次网络超时 会被显示成一条永久的权限限制，而真正的原因被丢掉， 用户没有任何线索去修。现在如实显示「本次查询失败」并带上具体原因
0.4.0
2026-08-13

新增

  • ⌫ / ⌦ 直接删除选中节点 —— 不必每次右键。走的是和右键菜单 同一个入口：确认框、⌘Z 撤回、连带删连线与组内子节点都保留。 在终端里打字时按退格不会误删（判据是「焦点不在任何可输入的地方」， 而不是「有没有选中节点」）

改进

  • 缩小画布时终端内容能撑得更久 —— 判据从「画布缩放」改成 「这行字在屏幕上有几像素高」。以前是一刀切，与节点多大、 字号多少都无关，把节点拉大照样被收成占位。现在能看到内容的缩放范围拉大一倍多
  • 中间那一档（内容已看不清、还没到全景）现在会显示恒定大小的 节点标题。以前那行字跟着画布一起缩，缩到远处只剩几个像素， 这一档等于「内容没了、字也读不出」
  • 全景视图去掉空闲节点的灰块 —— 「空闲」本来就没有语义， 却因为画布上多数节点都空闲而最抢眼。现在只留极淡的底， 蓝（运行中）/ 橙（需要你）/ 红（出错）照旧实心。扫一眼跳出来的只有真需要你的
0.3.0
2026-07-29

新增

  • 画布组绑定 git worktree —— 一个组一棵独立工作树， 并行的 agent 从物理上不再共享工作目录。组头显示分支与改动数；不是 git 仓库时这个功能完全不出现
  • 代理连接 —— tb db / tb ssh：agent 用得到你的数据库和服务器， 但拿不到连接串。密码走环境变量，不进进程参数表
  • 任务账本 —— 每次派活、每次代理连接、每次被拒绝的授权都留痕，可回溯
  • ⌘K 全局检索 —— 零输入时按紧急度排，有输入时按相关度排
  • 可分享的布局模板 —— 导出一套节点排布给别人。 模板里的启动命令不会自动执行，得你自己确认
  • Copilot 额度接入，三家都能查了
  • HUD 可折叠，账号卡默认精简

安全修复

  • 只读数据库连接能读出密码 —— psql 有一类客户端侧的反斜杠命令， 其中一个可执行任意本机命令。三道原有的闸都拦不住它，因为管的都不是这件事。 现在任何一行以反斜杠开头都直接拒绝，可写连接同样拒
  • 导入别人的画布等于执行其中的命令 —— 画布文件带着每个终端的启动命令，而确认框只说了「替换画布」。现在导入时全部摘掉， 账号绑定也一并摘（否则会静默用上你的订阅号并按它计费）
  • 浏览器节点共用 Cookie —— 授权按节点发，登录态却是共享的。 现在每个节点一个独立分区
  • 远程访问的能力开关点掉后立刻断服务，不再是「下次重启生效」
  • 审批记录的完整参数不再进入界面层，脱敏收口到唯一出口

修复

  • 终端底行被裁掉约四分之三行 —— 内边距长错了元素
  • 额度面板会把真实的订阅额度显示成「查不到」：订阅和按量计费可以同时存在， 判定顺序反了。现在先查，查不到才退回按量那句话
  • 指针在终端和浏览器内容上时，滚轮只滚内容，不再平移画布
  • 新节点落在视口正中，不再叠在已有节点里面
  • 节点变窄时终端自动缩字号
  • 关闭项目标签页时最后几步改动会丢（落盘有防抖，切板前没先快照）
